Objetivo de la practica

Crear una pagina con estructura HTML5 semantica, layout combinando Grid y Flexbox, tipografia que se adapte al tamaño de pantalla, y validar todo con Lighthouse y WAVE.

Actividades de la práctica

Paso 1: Estructura HTML

Etiquetas semanticas y separacion entre contenido y estilo.

Paso 2: Tipografia fluida

Uso de variables CSS, clamp() y calc().

Paso 3: Layout hibrido

Grid para la estructura general y Flexbox para las tarjetas.

Paso 4: Responsivo

Media queries y container queries.

Paso 5: Validacion

Correccion de errores con Lighthouse, WAVE y W3C.
